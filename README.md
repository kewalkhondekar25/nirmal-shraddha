# Nirmal Shraddha

Premium incense website built with Next.js.

## Develop

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Import [this repository](https://github.com/kewalkhondekar25/nirmal-shraddha) in Vercel.
2. Framework Preset: **Next.js** (auto-detected).
3. Optional env var:
   - `NEXT_PUBLIC_SITE_URL` = your production URL (e.g. `https://nirmal-shraddha.vercel.app`)

Build command: `npm run build`  
Output: Next.js default (no static export needed).
